# Changelog

## 0.1.0 - 2026-10-21

First public release of Portfolio Evidence Lab.

- Recursive fund look-through with dated disclosures, cycle detection, and explicit unknown holdings.
- Security overlap bounds, Ledoit-Wolf covariance, Euler volatility contributions, drawdown, and empirical weekly CVaR.
- Research candidates with constraints, cost scenarios, and a chronological holdout.
- Local CSV input contracts, an offline synthetic demo, evidence hashes, and replay.
- English and Chinese instructions, synthetic report screenshots, source-permission notes, and downloadable report examples.
- CI on Linux and Windows with Python 3.12 and 3.13, including wheel installation outside the source checkout, demo execution, verification, and replay.

All products, prices, holdings, and amounts in the public demonstration are fictional. The candidates are model outputs for research, not executable orders or return forecasts.
