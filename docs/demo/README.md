# Synthetic report preview

The screenshots in this directory show HTML generated by the production demo. They contain no real account information, fund prices, or provider holdings.

Download [the standalone HTML report](https://github.com/moonmu687-wq/portfolio-evidence-lab-oss/releases/latest/download/Portfolio_Decision_Report.html) and open it in a browser. No Python installation is needed to read it.

Download [the complete report and CSV bundle](https://github.com/moonmu687-wq/portfolio-evidence-lab-oss/releases/latest/download/synthetic-demo.zip) to use the report's sibling-file links. The standalone HTML contains the displayed tables, but its JSON and CSV links require this bundle.

| Fixed synthetic fixture | Value |
| --- | ---: |
| Identified underlying NAV share | 71.9% |
| Unresolved share | 28.1% |
| Exposure to fictional US:SYNTH_A | 31.15% |
| Fund 990001 capital weight | 35% |
| Fund 990001 volatility risk share | About 49% |

The bundle contains the generated report outputs, not the content-addressed evidence store. To verify inputs and replay a run, generate a workspace with `portfolio-lab demo` and use its manifest as described in the [main README](../../README.md#verify-and-replay).

See [maintenance instructions](../MAINTENANCE.md) to regenerate the screenshots. Screenshot rendering does not change the report or financial calculations.
